# Directory listings: copy-paste pack

Free directories give each tool a permanent backlink, and backlinks are what the sites need most right now (see the week-1 report). Submit each tool as its own listing where the directory allows it. Spread the work over a few days; it takes about 5 minutes per listing.

**Shared details for every listing**
- Maker / company: Rooh Sites (https://roohsites.com)
- Pricing: Free (no paid plan, no signup)
- Platforms: Web (works on desktop and mobile browsers, nothing to install)
- Privacy angle (good for "features"): runs entirely in the browser; files and data are never uploaded
- Logo: each site's `/favicon.svg`; screenshot / cover image: each site's `/og.png` (1200×630)
- Contact email: use your own

## Where to submit

| Directory | URL | How it works | Notes |
|---|---|---|---|
| AlternativeTo | alternativeto.net | Add the app, then add it as an alternative to the paid tools listed below | Highest value: people browse it for free alternatives |
| SaaSHub | saashub.com | Submit product, then add "alternatives" | Approval in a few days |
| Uneed | uneed.best | Free queue; pick a launch day | Small but steady traffic |

| Tiny Tools / Toolify-style lists | search "free online tools directory submit" | Varies | Skip any that ask for payment |

Tip: on AlternativeTo and SaaSHub, the "alternative to" links matter more than the description.
