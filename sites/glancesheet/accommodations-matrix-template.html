Accommodations Matrix Template for Teachers

Show one class's accommodations on a single chart: students down the side, accommodations across the top, a check mark where it applies. Built from the same student records as the sheets.

  • Landscape PDF
  • Numbered key
  • Initials by default
  • Free

Quick answer: An accommodations matrix is a chart for one class: rows are students (initials), columns are the accommodations any of them use, and a check mark shows who gets what. Add students below, tick the ones in the class, enter a class name and download the landscape PDF.

See the whole class in one glance

A general education teacher with six students on plans might hold six different documents, each with a different layout and a different level of detail. An accommodations matrix turns that into one chart. Down the left side are the students, across the top are the accommodations, and a check mark in a cell says that accommodation applies. A teacher can spot at a glance that four of six students need directions repeated, three need extended time, and two need to test in a small group, and then plan the lesson and the test day around that.

How the matrix is built

  • Rows. One row per ticked student, labelled with initials (or names if you turn initials-only off). Two students with the same initials are numbered so they stay distinct.
  • Columns. Every accommodation that at least one of the students uses, in the same order as the list in the editor. Accommodations nobody uses are left out, so the chart stays as narrow as it can.
  • Headers. Each column has a short rotated label and a number. The numbers match a key printed under the table, which gives each accommodation in full.
  • Pagination. With many students or many accommodations, the chart continues onto more pages and the headers repeat on every page, so no page is a mystery grid.
  • Layout. Landscape, on US Letter or A4, with the confidential line, a reminder that it is a summary, and the page number on each page.

How to use a matrix in the classroom

Print it once for the teacher's planning binder and read it before you plan a unit. Look at the columns with the most check marks: those are the supports that benefit the most students, and making them part of your usual routine, such as posting directions or giving a copy of notes to everyone who wants one, can reduce the work of doing them one student at a time.

Use the matrix on test days. Check which students need a separate setting, extra time or a reader, and arrange rooms and adults before the day. Use it with a substitute: pair it with the sub and para sheets so the sub sees both the class view and each student's page.

What the matrix does not show

The matrix lists accommodations only. It does not show modifications, goals, services or any detail on how an accommodation should be used. Where an accommodation has conditions, such as extended time on tests only or a calculator for certain tasks, the full plan has the detail. Treat the matrix as a planning aid, not a replacement for the plans themselves. Your school team decides what belongs in a student's plan. This page is general information, not legal advice.

Frequently asked questions

What is an accommodations matrix?

It is a grid for one class or period. Each row is a student and each column is an accommodation. A check mark means that accommodation is listed for that student. It lets a teacher see the whole class at once instead of opening each plan.

How do I make one for my class?

Add or select the students in your caseload who are in that class, tick them in the list, type a class name and press Download class matrix. If a student is in several classes, tick them for each one and print a matrix per class.

What happens when I have many students or accommodations?

The matrix paginates. When there are too many columns, it splits them across pages and repeats the student column and the headers on every page. When there are too many rows, it continues onto the next page with the same headers. The numbered key lists every accommodation in full.

Can the matrix show names instead of initials?

Yes, when you switch off Initials only. By default the rows show initials, which is safer for a page that may be posted at a desk or left in a folder.

Who should see the matrix?

The teacher and staff who work with those students. It collects several students' supports on one page, so handle it with the same care as the plans, and follow your district's rules on student records.
