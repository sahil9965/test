How to make an ABA graph in Excel

  1. Give each phase its own column. Session numbers in column A, baseline values in B, intervention values in C, with cells left blank outside each phase. Blank cells are what make Excel break the line between phases.
  2. Insert the chart. Select the data and choose Insert › Line or Area Chart › Line with Markers.
  3. Clean it up. Delete the gridlines and the chart title placeholder, and the legend unless there's more than one data path. Set the y-axis minimum to 0 (and the maximum to 100 for percentages).
  4. Draw each phase-change line. Insert › Shapes › Line, hold Shift to keep it vertical, place it halfway between the two sessions and set a dashed line style.
  5. Label the phases and axes. Add a text box above each phase and axis titles from the chart elements menu.
  6. Match the ABA style. Make the markers and lines black, then copy the chart into your report.

Menu names vary a little between Excel versions and on a Mac.

The catch with Excel graphs

Phase-change lines drawn as shapes don't move with the data, so when you add sessions or change the axis you have to move them by hand. A built-in linear trendline fits one whole series, so you need a separate series per phase to get a trend for each phase, and an aim line needs an extra series too. That's why many people keep the data in a spreadsheet but make the graph in a dedicated tool. Here, the CSV button exports your data back out, ready for Excel.

Google Sheets

The same approach works in Google Sheets: separate columns per phase, then Insert › Chart and choose a line chart, with point size set under the series options. Phase lines can be added with the drawing tool. Or paste the same columns here.

Frequently asked questions

Is there a free ABA graph template for Excel?

Yes. Download the CSV template above. It opens in Excel and Google Sheets with Session, Date, Phase and value columns, and pastes straight into this graph maker.

Why does Excel connect my baseline and intervention data?

Because they're in the same column. Excel only breaks a line at blank cells, so put each phase in its own column, or paste the data here, where the break is automatic.

Can I paste the one-column-per-phase layout here?

Yes. If every row has a value in only one of the phase columns, the paste importer reads each column as a phase.

Can I get my data back into Excel?

Yes. The CSV button downloads Session, Date, Phase and the values, ready to open in Excel.
