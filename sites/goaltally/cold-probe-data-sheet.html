Cold Probe Data Sheet

List the targets, probe each one once at the start of the session, and circle Y or N. Track when each target was introduced and mastered, all on one page.

  • Free
  • No signup
  • Nothing uploaded
  • Works offline

Runs entirely in your browser. Use student initials, not names.

Quick answer: Cold probe data records whether the learner gets each target right on the first opportunity of the day, before any teaching or prompting. That's what “cold” means. Mark Y for a correct, unprompted first response and N for anything else. A target is usually counted as mastered after a set number of consecutive Y probes, such as 3 days in a row, and then moved to maintenance.

Why probe instead of recording every trial?

A probe takes a few seconds per target, so one sheet can track 10, 20 or more targets at once and teaching time isn't spent writing. Because the probe comes before any help that day, a Y is a strict test of what the learner can do independently. The trade-off is detail: you won't see progress within a session. Many programs use both, with cold probes for mastery decisions and trial-by-trial data for new or difficult targets.

How to run and record a cold probe

  1. Probe before teaching. Present each target once, the same way every day, before any practice on it.
  2. Give no prompts. Wait a set time for a response, for example 3 to 5 seconds.
  3. Circle Y or N. Y if correct and independent; N if incorrect, no response, or a prompt was needed.
  4. Then teach as planned. Teaching trials aren't recorded on the probe sheet.
  5. Record mastery. When a target meets the criterion, write the date in Date mastered and add a new target.

Graphing cold probe data

Two graphs are common. The first is the percentage of targets correct each day (Y ÷ targets probed × 100); on-screen scoring adds this point to the goal's graph automatically. The second is a cumulative graph of targets mastered, where the line steps up by one each time a target meets the criterion. For that one, enter the running total in the graph maker and label the y-axis “Number of targets mastered”.

Frequently asked questions

What does “cold” mean in a cold probe?

The first opportunity of the day, before any teaching, prompting or warm-up on that target. It tests what the learner can do on their own.

How many consecutive Y probes count as mastered?

Your team decides. Common criteria are 2 or 3 consecutive sessions, sometimes across two different staff members. Write it in the mastery criterion box so it prints on the sheet.

How many targets fit on one sheet?

About 20 on a portrait page with the default layout. Longer lists continue onto more pages, with the column headers repeated.

Can I probe on a tablet?

Yes. Use Score a session on screen, tap Y or N for each target, and save. The day's percentage goes onto the goal's graph and can be filled into the printed sheet.
