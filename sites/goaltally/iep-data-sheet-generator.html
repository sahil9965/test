Which data sheet fits the goal?

The wording of the goal usually tells you how it should be measured. Match the criterion to the sheet:

If the goal says…You're measuringUse this sheet

“…independently” or “…with no more than a gestural prompt”The level of help on each trialPrompt level
“…will identify 20 sight words” or “…across 3 consecutive probes”Targets correct on the first tryCold probe

How to set up a data sheet

  1. Choose the measurement type. The options below it change to match: trials and sessions, prompt codes, targets, steps, behaviors or interval length.
  2. Add initials and the target. Use initials only. Paste the goal or objective and the mastery criterion so whoever collects data knows what counts.
  3. Adjust the layout. Set the number of trials, date columns, steps, targets, episode boxes or the interval length. The preview updates as you type.
  4. Download or print. US Letter or A4, portrait or landscape. Long sheets continue onto more pages with the column headers repeated.
  5. Save the goal (optional). Saved goals stay on this device. Open Backup, restore, print all & export to print every sheet for one student in a single PDF.

Scoring on a tablet or phone

Score a session on screen opens a tap-friendly version of the sheet: tap + or – for each trial, tap prompt codes, count with a big +1 button, time episodes with a stopwatch, or run an interval timer that beeps at each interval. Save the session and GoalTally works out the percentage or rate, adds it to the goal's graph, and can fill it into the printed sheet, including the totals and percentage rows.

Tips for data you can trust

  • Define the behavior or response in observable words, so two people would score the same session the same way.
  • Decide when data is taken: every trial, the first trial of the day (a probe), or a set observation period. Keep it the same from session to session.
  • Keep the sheet with the materials and score straight away. Data written from memory at the end of the day is less accurate.
  • Graph at least weekly. Patterns are much easier to see on a graph than in columns of numbers.
  • Check agreement now and then. Have a second person score the same session independently. For trial data, agreement = agreements ÷ (agreements + disagreements) × 100.

Frequently asked questions

Are the data sheets really free?

Yes. Every measurement type, unlimited PDFs, printing, saved goals, on-screen scoring and bulk printing are free with no account. Each sheet carries a small “Made with GoalTally” credit in the footer.

Can I change the prompt hierarchy?

Yes. On prompt level and task analysis sheets, edit the hierarchy list, one code per line in the form FP = Full physical. The code labeled Independent (or I) is the one counted for % independent.

Can I add my school or clinic logo?

Yes. Upload a PNG or JPG under Page. It's stored only in this browser and printed at the top right of every sheet.

Can I print all goals for one student at once?

Yes. Save each goal with the same student initials, then open Backup, restore, print all & export, choose the student and download one PDF with every sheet.

Is this IEP data sheet generator FERPA or HIPAA compliant?

GoalTally doesn't receive, store or transmit student information: everything stays in your browser. It makes no compliance claims, because that depends on how your organization handles devices and printed sheets. Use initials and follow your district or clinic policy.
