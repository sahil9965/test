Prompt Level Data Sheet

Record how much help each trial needed, from full physical to independent. Edit the prompt codes to match your hierarchy, print the sheet, or tap codes on a tablet.

  • Free
  • No signup
  • Nothing uploaded
  • Works offline

Runs entirely in your browser. Use student initials, not names.

Quick answer: A prompt level data sheet records the level of prompting a learner needed on each trial, using codes such as FP (full physical), PP (partial physical), M (model), G (gestural), V (verbal) and I (independent). The usual summary is % independent: trials scored I ÷ trials run × 100. Codes moving toward I across sessions show that prompts are being faded.

Common prompt codes

CodePromptWhat it looks like
FPFull physicalHand-over-hand guidance through the whole response.
PPPartial physicalA light touch or nudge, for example at the elbow or wrist.
MModelYou demonstrate the response for the learner to imitate.
GGesturalPointing, nodding or looking toward the correct answer.
VVerbalA spoken hint or part of the answer (“It starts with b…”).
IIndependentA correct response with no prompt after the instruction.

Some teams add visual prompts (a picture or written cue) or positional prompts (placing the correct item closer to the learner). Add them to the hierarchy in the sheet options. Whatever code you label Independent is the one counted.

Most-to-least or least-to-most?

Most-to-least prompting starts with the most supportive prompt and fades to less help as the learner succeeds. It's often used for new skills to keep errors low. Least-to-most prompting starts by waiting for an independent response and adds help only when needed, so the learner gets a chance to respond independently on every trial. The sheet works for both: list the codes in the order your team uses them.

How to use the sheet

  1. Set the layout. Choose trials per session and how many sessions (date columns) the sheet holds.
  2. Check the hierarchy. Edit the list if your program uses different codes or more levels.
  3. Circle one code per trial: the level of help the learner needed to respond correctly.
  4. Total the session. Count the I's and write # independent and % independent at the bottom of the column.
  5. Graph % independent. Or score on screen and the graph point is added for you.

Graphing prompt level data

% independent is the simplest line to graph. Some teams also graph the prompt level itself as a number, for example FP = 0 up to I = 5, to show fading before independence appears. If you do that, fix the numbers in advance and label the y-axis clearly. You can enter either kind of value in the ABA graph maker, and use two data series to show both on one graph.

Frequently asked questions

What is a prompt hierarchy?

An ordered list of prompts from most to least support (or the reverse), such as full physical, partial physical, model, gestural, verbal, independent. It tells staff which prompt to try next so help can be faded systematically.

Can I change the prompt codes?

Yes. Edit the hierarchy box, one code per line as code = meaning. The codes print in every box and appear as tap buttons when you score on screen.

What if the learner is wrong even with a prompt?

Record the most supportive prompt you gave and follow your program's error-correction procedure. Only independent correct responses count toward % independent.

How is % independent calculated?

Trials scored I ÷ trials run × 100. 4 independent trials out of 10 is 40%.
