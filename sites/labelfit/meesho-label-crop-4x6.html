Meesho Label Crop to 4x6 for Thermal Printers

A Meesho label download is usually an A4 PDF with the shipping label in one area and the tax invoice in another. Crop out just the label and print it on a 4x6 (100 × 150 mm) thermal sticker. The file stays in your browser.

Quick answer: To crop a Meesho label for a 4x6 thermal printer, open the label PDF in LabelFit, check that the green box covers the shipping label and not the tax invoice, and download the PDF. Print it on 4x6 (100 × 150 mm) labels at 100% or Actual size. If the box is wrong on page 1, drag it once and press Save layout. After that, every PDF with the same design crops in one click.

How to crop a Meesho label and print it on 4x6 thermal labels

  1. Download the label PDF. Download your Meesho labels the way you normally do and keep them as a PDF. A file with many orders is fine: LabelFit checks every page on its own.
  2. Add it to LabelFit. Choose the PDF above. Under Print on, pick 100 × 150 mm, or 4 × 6 in if that is what is printed on your roll.
  3. Check the green box on page 1. The box should wrap the shipping label (courier name, barcode, address) and leave out the tax invoice. The preview beside it shows exactly what will print.
  4. Drag the box if it is off, then Save layout. Drag the box or its corners until the whole label is inside, with a millimetre or two of white paper around it. Type a name such as Meesho A4 label and press Save layout. The box is applied to every page of the file.
  5. Download and print at 100%. Press Download PDF, open it, and print on 4x6 labels with the paper size set to 4 × 6 in or 100 × 150 mm and the scale at Actual size.

What a Meesho label PDF usually looks like

A downloaded Meesho label is normally an A4 page. One part of the page holds the shipping label: the courier's name, a barcode with the AWB number, the delivery address and a return address. Another part holds the tax invoice, a table of items with totals. A file with many orders usually has one order per page. Courier partners use different designs, and marketplaces change them from time to time, so treat this as a general picture and not a promise about your file.

A thermal printer cannot print that page as it is. Sent to a 4x6 printer with Fit to page, the whole A4 sheet shrinks to about 48% (100 ÷ 210), and the barcode becomes too thin to scan. The fix is to cut the label out first, which is what the steps above do.

What LabelFit does by itself, and what you check

LabelFit looks for the label automatically. It reads each page, finds the blocks of ink, and treats the block with barcodes and address lines as the label. Words such as “Tax invoice”, “Qty” and “Subtotal” mark a block as an invoice, which is left out by default.

Be clear about the limits. We built and tested this flow on sample A4 files with a label above an invoice, not on live Meesho downloads, and LabelFit has no special support for Meesho. Marketplaces change their label layouts from time to time, so check the first page. If the box is off, drag it once and save the layout.

Save the crop once, reuse it every day

A saved layout remembers where the label sits on the page, as a share of the page's width and height. It never stores the label itself. Because it is a position and not a guess, it is applied to every page of every file with the same design, including the pages that auto-detect would have got wrong.

  1. Save it. Fix the box on page 1, type a name, press Save layout. Under More options you will find it listed in Saved layouts.
  2. Use it next time. Open LabelFit and check that your layout is selected under Label from (it sits under My saved layouts). Then add the day's PDFs.
  3. Glance at the thumbnails. Each page should say “1 label”. A page that says “No label” needs a box added with + Add a crop box, or Skip this page.
  4. Keep a spare copy. Layouts live in this browser on this device. Export layouts downloads them as a small file and Import layouts loads that file on another computer.

Keep the invoice as a separate page

If you need the invoice with the parcel, press + Add a crop box, drag it over the invoice and set Use this box as to Packing slip (own page). Save the layout again under a new name such as Meesho label + invoice. Each order then gives you two 4x6 pages: the label, then its invoice. You can also set Packing slips to Print on their own page under More options and let LabelFit find the invoice itself. See how to split a label and packing slip for more.

One honest warning: a full-width A4 invoice has to be turned sideways and shrunk to fit a 4x6 page. In our sample test it came out at about 76% of its size, and LabelFit flags anything under 80%. The small print gets small. If you need a readable invoice, print the original A4 page on plain paper instead. A kept invoice gets a small “Made with LabelFit” line underneath.

Meesho label print settings for a thermal printer

  • Paper size: 4 × 6 in or 100 × 150 mm, the same as your roll. If it is not listed, add a custom size in the printer preferences.
  • Scaling: Actual size or 100%. The PDF is already 4x6, so Fit to page only shrinks it again.
  • Orientation: portrait. The PDF is already upright.
  • Media type: labels with gaps. After loading a new roll, run the printer's calibration so it knows where each label starts.
  • Darkness: start with the default. If bars look pale, raise it one step. Too dark makes the bars bleed together and can stop the barcode from scanning.
  • Test first: print one label and scan it with your phone before you print the batch.

The tool also has a copyable step list under Print settings for a perfect 100% print for Acrobat, Chrome or Edge, and Mac Preview.

Busy days: many orders in one PDF

A multi-page PDF becomes one 4x6 page per label, in the same order. You can drop several PDFs at once and download a single combined file, then print it in one run. Use the arrows under the preview to flip through the output pages before you print. If one file comes from a different courier layout, use a separate saved layout for it, or convert it as its own batch. When a very large file feels slow, split the day's PDFs into two or three batches.

Printing from a phone to a Bluetooth printer? Choose Image instead of PDF and follow the phone printing guide.

Your buyers' details stay on your device

Labels carry names, phone numbers and home addresses. LabelFit opens the PDF and builds the new one inside your browser tab. There is no upload step, and after your first use it keeps working with the network switched off. One thing to know: the converted PDF hides the rest of the original page (such as the invoice) rather than deleting it. That is fine for printing. If you send the converted file to someone else, choose Image output instead, because an image holds only what you see.

Frequently asked questions

How do I print a Meesho label in a thermal printer?

Crop the label out of the A4 PDF first, then print the cropped file. In LabelFit, add the PDF, check the green box, download the 100 × 150 mm PDF and print it at Actual size. That gives you a proper Meesho label 4x6 print instead of a shrunken A4 page.

Does LabelFit detect Meesho labels automatically?

LabelFit looks for the label automatically, using barcodes, address lines and borders. It has no special support for Meesho, and marketplaces change their label layouts from time to time, so check the first page. If the box is off, drag it once and save the layout.

What size is a Meesho label on a thermal printer?

4x6 (100 × 150 mm) is the common thermal label size in India. Choose the size printed on your roll under Print on, and set the printer to the same paper size.

Do I have to crop every Meesho PDF by hand?

No. Fix the box once and press Save layout. The saved layout is then used for every page of every file with the same design, so each later PDF takes one click.

Can I print the tax invoice as well?

Yes. Add a second crop box over the invoice and set it to Packing slip (own page), or set Packing slips to Print on their own page. The invoice is shrunk to fit 4x6, so print the original A4 page if you need it to be easy to read.

Why does my Meesho label print small or in a corner?

Usually the printer is still set to A4 paper, or the print dialog uses Fit to page. Download the cropped 4x6 PDF, set the paper size to 4 × 6 in or 100 × 150 mm, and print at Actual size.

Are my customers' addresses uploaded anywhere?

No. The PDF is read and converted inside your browser, so names, phone numbers and addresses stay on your device.
